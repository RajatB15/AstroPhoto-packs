# AstroPhoto region packs

Downloadable map data for the AstroPhoto iPhone app's Peaks mode (offline mountain names and terrain horizon).
This repository holds data files only. The app source is not here.

## What's inside
- `manifest.json`: the list of packs, with versions, sizes and SHA-256 checksums (added with the first release).
- Region packs (terrain elevation tiles plus peak names), published as GitHub Release assets.

Packs are generated by the AstroPhoto pack-builder tool and are not edited by hand.
